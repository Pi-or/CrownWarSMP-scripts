# CrownWarSMP-scripts
The scripts and functions used in CrownWarSMP for all your open-source needs!
Before pasting the whole script in your Minecraft server make sure to place a crafting table at (x:0.5, y:~, z:0.5).
Also, spawn the quest giver in their respective places, read the Questgiver.txt for more info.
For pasting the scripts in your Minecraft server make sure to run version 1.21.11 and install the plugin Skript. Make sure it is version 2.16. To paste the scripts goto /files/plugins/Skript/scripts/ then upload the files. Start the server then type /sk reload special_craft.sk and /sk reload crownwar_systems.sk it should reload beautifully. Have fun!
